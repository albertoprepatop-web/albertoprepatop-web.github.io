# Listas

Dos listas para texto corrido: `lista-puntos` para explicar y `lista-visto` para lo que está incluido o hecho.

- **Qué pone quien la usa:** un `<ul class="lista-puntos" role="list">` o un `<ul class="lista-visto" role="list">` con elementos `<li>` de una o dos líneas.
- **`lista-puntos`:** un punto de 7 px en `pizarra-linea`, para matices y condiciones: «La IA guía, recuerda y redacta».
- **`lista-visto`:** una marca de verificación en `tinta`, solo para lo que se incluye o ya se ha hecho: «Servidor e instalación».
- **De tres a cinco elementos.** Si son más, mejor tarjetas o una tabla.
