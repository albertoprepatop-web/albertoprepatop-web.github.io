# Laminas

Hojas de referencia, no piezas para usar.

- `construccion.png`: construcción del logotipo y área de respeto.
- `usos-incorrectos.png`: lo que no se hace con el logotipo.
- `tablero.png`: el logotipo en positivo, en negativo y el isotipo, de 256 a 16 px.
- `kit.png`: las 22 ilustraciones en una hoja. Se rehace con `bash directoria/presentacion/herramientas/kit.sh` (ver `directoria/ilustraciones/LEEME.md`).
- `vista-general.png`: las 35 diapositivas de la presentación comercial, con el anexo. Se rehace con `node directoria/presentacion/herramientas/vista-previa.mjs directoria/presentacion --all …` (ver el `LEEME.md` de esa carpeta).
