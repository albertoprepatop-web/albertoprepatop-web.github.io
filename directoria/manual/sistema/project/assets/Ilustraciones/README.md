# Ilustraciones

Veintiuna ilustraciones planas de 240 × 240, cada una sobre su disco `linea`. Se usan desde 96 px, sin recolorear, deformar, girar ni quitar el disco. El naranja (`chispa`, sobre pizarra) aparece solo donde actúa la IA: la luz del servidor y la insignia de lo que prepara. Las reglas y las parejas recomendadas están en la sección Ilustraciones.

- **Lugares:** `colegio-servidor` (la imagen clave), `servidor`, `colegio`, `nube-claude`.
- **Personas:** `direccion`, `jefatura`, `secretaria`, `docente`, `orientacion`, `sustituto`, `familia`.
- **Documentos e iconos:** `documento-ia`, `circular`, `acta`, `ficha`, `correo`, `calendario`, `candado`, `microfono`, `reloj`, `alerta`.
